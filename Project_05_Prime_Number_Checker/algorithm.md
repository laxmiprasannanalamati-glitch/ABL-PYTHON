# Algorithm

1. Start.
2. Read number n.
3. Set prime to True.
4. If n is less than 2, set prime to False.
5. Otherwise, repeat from 2 to n-1.
6. If n is divisible by the current number, set prime to False and stop the loop.
7. If prime is True, display prime number; otherwise display not a prime number.
8. Stop.
