# Flowchart

**Standard flowchart symbols:** `( )` Start/Stop, `/ /` Input/Output, `[ ]` Process, `< >` Decision.

```text
              ( START )
                  |
                  v
             / Input name /
                  |
                  v
          / Input roll number /
                  |
                  v
            / Input branch /
                  |
                  v
          [ Create student tuple ]
                  |
                  v
            [ Unpack tuple ]
                  |
                  v
       / Display student details /
                  |
                  v
               ( STOP )
```

This uses the standard Start/Stop, Input/Output, and Process symbols.
