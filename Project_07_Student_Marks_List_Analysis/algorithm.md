# Algorithm

1. Start.
2. Read five marks and store them in a list.
3. Set highest and lowest to the first mark.
4. Set total to 0.
5. Traverse each mark using a `for` loop.
6. Add each mark to total.
7. Update highest if the mark is greater than highest.
8. Update lowest if the mark is less than lowest.
9. Calculate average as total divided by 5.
10. Display the list, highest, lowest and average.
11. Stop.
