# Flowchart

**Standard symbols:** `( )` Start/Stop, `/ /` Input/Output, `[ ]` Process, `< >` Decision.

```text
          ( START )
              |
              v
       / Input string /
              |
              v
       [ Reverse string ]
              |
              v
    < String = reversed string? >
          /              \
        Yes               No
         |                 |
         v                 v
 / Display Palindrome / / Display Not Palindrome /
          \               /
           \             /
            v           v
              ( STOP )
```
