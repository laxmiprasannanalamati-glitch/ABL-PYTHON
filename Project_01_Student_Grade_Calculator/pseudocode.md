# Pseudocode

```text
START

INPUT name
INPUT mark1, mark2, mark3

CONVERT marks to numbers

SET total = mark1 + mark2 + mark3
SET average = total / 3

IF average >= 90
    grade = A
ELSE IF average >= 75
    grade = B
ELSE IF average >= 60
    grade = C
ELSE IF average >= 50
    grade = D
ELSE
    grade = F
END IF

DISPLAY name, total, average, grade

STOP
```
