# Algorithm

1. Start.
2. Read the student's name.
3. Read marks for three subjects.
4. Convert the marks to numeric values.
5. Calculate `total = mark1 + mark2 + mark3`.
6. Calculate `average = total / 3`.
7. Use an `if-elif-else` ladder to determine the grade.
8. Display the student's name, total, average and grade.
9. Stop.
