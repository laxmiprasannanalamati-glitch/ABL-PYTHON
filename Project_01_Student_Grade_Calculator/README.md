# Project 01 - Student Marks, Average and Grade Calculator

## Problem Statement
Write a Python program to read a student's name and marks in three subjects. Calculate the total and average marks and assign a grade using an `if-elif-else` ladder.

## Objectives
1. Read student details using input statements.
2. Use type conversion to accept marks as numbers.
3. Calculate total and average using arithmetic operators.
4. Assign a grade using decision-making statements.

## Assumptions
- Marks are entered for exactly three subjects.
- Each mark is between 0 and 100.
- Grade is based on the average.

## Grade Rules
- 90 and above: A
- 75 to 89.99: B
- 60 to 74.99: C
- 50 to 59.99: D
- Below 50: F

## Syllabus Concepts
Unit I: variables, data types, input/output, type conversion, arithmetic operators.

Unit II: `if`, `elif`, `else` decision-making statements.
