# Algorithm

1. Start.
2. Read two numbers.
3. Read the operator.
4. If the operator is `+`, add the numbers.
5. Else if it is `-`, subtract the numbers.
6. Else if it is `*`, multiply the numbers.
7. Else if it is `/`, divide the numbers.
8. Otherwise display invalid operator.
9. Display the result.
10. Stop.
