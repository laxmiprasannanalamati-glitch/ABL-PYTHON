# Pseudocode

```text
START
INPUT first number
INPUT second number
INPUT operator

IF operator = +
    result = first number + second number
ELSE IF operator = -
    result = first number - second number
ELSE IF operator = *
    result = first number * second number
ELSE IF operator = /
    result = first number / second number
ELSE
    DISPLAY Invalid operator
END IF

DISPLAY result
STOP
```
